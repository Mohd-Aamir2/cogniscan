# Cogniscan
HTML+CSS+JS (frontend) → fetch() → Node.js+Express → MongoDB

## Run
1. Start MongoDB locally (or use an Atlas URI).
2. `cd backend && cp .env.example .env && npm install && npm start`
3. Open http://localhost:5000  (Express serves the frontend too)

API: POST /api/register, /api/login, /api/logout · GET /api/profile · POST/GET /api/assessments · GET /api/assessments/:id · GET/PUT /api/patients/me
Not a diagnostic device. Screening/trend observation only.
